一、春季穿搭建议
1. 气温特点：10-22℃，早晚温差大，需灵活搭配。
2. 核心单品：薄款风衣、牛仔外套、针织开衫、卫衣、白衬衫。
3. 穿搭技巧：洋葱式叠穿，内搭T恤+中层衬衫+外套，方便随时增减。
4. 推荐搭配：
   - 通勤：白衬衫+高腰烟管裤+乐福鞋+薄风衣
   - 休闲：条纹T恤+直筒牛仔裤+小白鞋+棒球帽
   - 约会：碎花连衣裙+针织开衫+玛丽珍鞋
   - 运动：卫衣+运动裤+跑鞋+帆布包

二、夏季穿搭建议
1. 气温特点：25-38℃，高温闷热，需清凉透气。
2. 核心单品：棉麻T恤、短裤、连衣裙、背心、防晒衣、凉鞋。
3. 穿搭技巧：选择浅色系吸热少，棉麻面料透气，适当露肤降温。
4. 推荐搭配：
   - 通勤：冰丝衬衫+九分裤+低跟凉鞋+通勤包
   - 休闲：纯色T恤+牛仔短裤+人字拖+帆布包
   - 海边：比基尼/沙滩裙+草帽+墨镜+凉拖
   - 日常：宽松棉麻裙+平底凉鞋+草编包

三、秋季穿搭建议
1. 气温特点：8-25℃，早晚凉、中午暖，层次感穿搭黄金季节。
2. 核心单品：卫衣、针织衫、风衣、马丁靴、西装外套、围巾。
3. 穿搭技巧：善用叠穿创造层次感，大地色系为主色调。
4. 推荐搭配：
   - 通勤：针织衫+半裙+中跟短靴+托特包
   - 休闲：卫衣+运动裤+帆布鞋+棒球帽
   - 街拍：西装外套+高腰牛仔裤+乐福鞋+贝雷帽
   - 温柔风：针织开衫+碎花裙+短靴+链条包

四、冬季穿搭建议
1. 气温特点：-10-10℃，寒冷干燥，需注重保暖。
2. 核心单品：羽绒服、大衣、毛衣、保暖内衣、围巾手套帽子。
3. 穿搭技巧：内薄外厚，中间留空气层保暖；毛领、围巾等配饰增加温暖感。
4. 推荐搭配：
   - 通勤：羊绒毛衣+直筒裤+大衣+短靴+围巾
   - 休闲：连帽卫衣+羽绒马甲+牛仔裤+雪地靴
   - 保暖：保暖内衣+高领毛衣+羽绒服+加绒裤+雪地靴
   - 轻熟风：高领打底+西装大衣+烟管裤+切尔西靴

五、不同体型穿搭技巧
1. 梨形身材（上半身瘦、胯宽腿粗）
   - 重点：突出上半身优势，弱化下半身。
   - 上装：泡泡袖、荷叶边、亮色上衣。
   - 下装：A字裙、阔腿裤、直筒裤，避免紧身裤。
   - 避免：百褶裙（膨胀感强）、紧身牛仔裤。

2. 苹果形身材（腰腹赘肉、四肢纤细）
   - 重点：遮盖腰腹，露出四肢。
   - 上装：V领、宽松版型、垂感面料。
   - 下装：直筒裤、阔腿裤、A字中长裙。
   - 避免：高腰紧身款、束腰设计、腰部装饰过多。

3. H形身材（肩腰胯宽度接近、缺少曲线）
   - 重点：制造曲线感，增加层次。
   - 上装：荷叶领、泡泡袖、收腰设计。
   - 下装：百褶裙、包臀裙、有腰线的连衣裙。
   - 避免：直筒型无腰线裙装、过于宽松的款式。

4. 沙漏形身材（肩胯同宽、腰细、曲线明显）
   - 重点：展示腰线，突出曲线优势。
   - 推荐：收腰连衣裙、紧身牛仔裤、裹身裙。
   - 避免：Oversize风格（遮挡曲线）、直筒型服装。

5. 倒三角身材（肩宽背厚、下半身窄）
   - 重点：弱化肩部，突出下半身。
   - 上装：V领、深色上衣、简约款式，避免垫肩和泡泡袖。
   - 下装：阔腿裤、A字裙、亮色下装。
   - 避免：一字肩、肩部装饰过多的款式。
